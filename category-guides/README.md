# Category Production Guides

The six Markdown playbooks in this folder define what good video means for each enabled AI Content Factory category. The server should inject the matching guide into the script-generation prompt; simply storing the files is not enough.

Shared rules:
- Match the user's selected category, language and format.
- Do not invent current facts, quotes, stats, product features or lyrics.
- Make the first 1–3 seconds specific and valuable, not generic clickbait.
- Use a clear beginning, useful middle and satisfying ending.
- Match visuals, narration, captions, title and hashtags to the actual content.
- Produce truthful metadata and 3–5 relevant hashtags.
- Run quality checks before scheduling. If research/rendering/publishing fails, report the actual error; do not claim upload succeeded.
